Images and videos. The AI scans every file and marks what it thinks is a watermark.

How it works

  1. Detect — for video we use the time axis: a mark that moves (Sora/Veo/Kling) is found from the temporal median, a fixed logo from edge-persistence + variance attenuation. For images we fuse tile-repeat, corner, stroke-text and translucency cues.
  2. Refine — paint with the brush to add or erase parts of the red mask.
  3. Remove — moving marks are healed with a motion-compensated temporal clean plate; fixed marks with optical-flow propagation of real pixels from neighbouring frames (LaMa / ProPainter / hosted APIs are pluggable backends).
